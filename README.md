# TempoStatusBarApp

A personal macOS menu bar app, maintained by one author for their own use.
Issues and pull requests may not receive a timely response.

TempoStatusBarApp shows how many days have passed since your last Jira Tempo
worklog submission, using a color-coded status indicator so you can tell at a
glance whether you are overdue. It targets the **Tempo Server / Data Center**
REST API (not Tempo Cloud).

## Features

- Configure your Jira instance URL, API token, and (optional) user ID from the UI
- Polls the Jira Tempo REST API once an hour for your latest worklog
- Menu bar shows days since your last worklog with a configurable warning threshold
- Three color-coded status levels:
  - ✅ Green — within the threshold
  - ⏰ Orange — one day over the threshold
  - 🚨 Red — more than one day over the threshold
- Automatically recovers after transient network drops (e.g. VPN reconnect)
- Optional "Launch at Login" (macOS 13+)

## Requirements

- macOS 12.0 or later (the app runs on macOS 12; the Launch-at-Login toggle
  requires macOS 13 or later)
- Xcode 16 or later to build from source

## Building from source

The app has no external package dependencies — everything lives in a single
Xcode project.

1. Clone this repository.
2. Open `TempoStatusBarApp.xcodeproj` in Xcode 16 or later.
3. Build and run the `TempoStatusBarApp` scheme.

Or from the command line:

```sh
xcodebuild -project TempoStatusBarApp.xcodeproj -scheme TempoStatusBarApp build
```

The version string shown in the About dialog is generated by a Run Script build
phase at build time, so build the project once before that value resolves.

The app runs as a menu bar agent (`LSUIElement`), so it has no Dock icon — look
for its status item in the menu bar after launch.

## Configuration

All configuration is done from the app's **Settings** popover (open it from the
menu bar item):

| Field | Description | Default |
|---|---|---|
| Jira Instance URL | Your full Jira base URL, e.g. `https://jira.example.com`, including `https://` | — |
| API Token | A Jira Personal Access Token (Server/Data Center) | — |
| Account ID | Your Jira username; optional — can be auto-detected via `/myself` | — |
| Warning Threshold | Days without a worklog before the warning state activates | 7 |
| Launch at Login | Start the app automatically at login (macOS 13+) | off |

Use **Auto-detect** to resolve your username from the API token, and **Test
Connection** to verify your settings before saving. Credentials are stored in
the macOS Keychain, never in plain text.

## How it works

The app authenticates with `Authorization: Bearer <token>` and calls two
Tempo Server / Data Center endpoints:

| Method | Path | Purpose |
|---|---|---|
| GET | `/rest/api/2/myself` | Resolve your Jira username/key from the API token |
| GET | `/rest/tempo-timesheets/3/worklogs` | Fetch your recent worklogs |

For a fuller description of the architecture, state management, and error
handling, see [docs/OVERVIEW.md](docs/OVERVIEW.md) and
[docs/api-design.md](docs/api-design.md).
